## Codebase Patterns

- **Link checking here needs a GitHub-accurate slugifier.** Headings in this tree are full of
  spaced em dashes (`## 1. Where this actually is — 2026-08-27`). GitHub drops the em dash and maps
  *each remaining space to its own hyphen*, producing `...is--2026-08-27`. A slugifier that collapses
  `\s+` to one hyphen reports 25 false positives across these docs. Correct recipe: lowercase, strip
  backticks, unwrap `[text](url)` to `text`, delete everything not `\w`/space/hyphen, then
  `.strip().replace(' ', '-')`. Skip fenced code blocks when collecting headings.
- **The banner regex.** `head -5 "$f" | grep -q '^> \*\*Status:\*\*.*\*\*Updated:\*\*.*\*\*Owner:\*\*'`
  — the banner is always line 3, a blockquote, immediately after the `# Title` and a blank line.
- **`verify.sh` exits 0 on a skip.** Never read exit 0 as green. Read the summary line. On these
  machines it is always `4 passed, 1 skipped, 0 failed` with `Gradle build — no JDK on PATH`.

### Learnings for future iterations

- **`docs/reference/android-build.md` is stamped `Draft`, not `Live`, on purpose — US-2 owes it a
  correction.** It tells the reader to run `gradle :android:assemble`. The repo has a checked-in
  wrapper, and `gradle/wrapper/gradle-wrapper.properties` opens with a comment explaining that bare
  `gradle` uses whatever the runner image ships (9.7.0 on 2026-08-27) and is therefore not
  reproducible. Everything else in that file checks out against `android/build.gradle.kts`:
  `minSdk 26`, `targetSdk 35`, `compileSdk 35`, JDK 17 — and against the root `build.gradle.kts`:
  AGP 8.6.1, Kotlin 2.0.21, wrapper Gradle 8.10.2. The "authoring machine has no JDK" claim is
  still true and still verifiable by running the gate.
- **US-2 already has one confirmed drift target (above) and should start from the tree, not the
  docs.** The cheap sweep for the rest: grep every backticked path and command out of `docs/**` and
  test each against the filesystem, then check the vector counts (40 / 39 / 1 / 3) and the two I6
  disk numbers (4 KiB Swift / 0 KiB Kotlin) against `Tests/Conformance/` and both ports' test code.
- **US-3 will need `docs/archive/` to exist**, and git cannot commit an empty directory — it will
  come into being with the first archived document, or not at all. If nothing turns out to warrant
  archiving, say that in the record rather than creating a placeholder.
- **The three dead-code docs cross-reference each other by anchor heavily** (`dead-code-inventory`,
  `-removal`, `-undecidable`: 25 inter-document anchor links). Renaming any heading in those three
  breaks links silently. Re-run the anchor check after touching them.
